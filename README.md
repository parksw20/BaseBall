# ⚾ BaseBall — 게이지 야구 3D

Three.js 기반 브라우저 야구 게임. 설치 없이 바로 플레이:

**▶ https://parksw20.github.io/BaseBall/**

## 조작

| 역할 | 조작 |
|---|---|
| 타자 | 마우스로 배트 조준 · **클릭=풀스윙** · 투구 전 길게 누르면 번트 자세(떼면 배트 빼기) · 방향키/WASD 타자 이동 |
| 투수 | 마우스로 조준 → 누르면 힘 게이지(1.5초) → 드래그=변화구 → 떼면 투구 (예상 궤적 프리뷰) |
| 작전 | 주자 있을 때 좌측 도루 버튼 · 로스터의 불펜 클릭=투수 교체 |
| 기타 | 우상단 🔊 음소거 · 🐞 디버그(중앙 직구) · 🌙 야간 경기 |

## 특징

- 프로야구 룰: 볼카운트·병살·희생플라이·도루·연장·끝내기
- 실제 판정 물리: 타이밍+위치 접촉, 송구 vs 주자 레이스, 릴레이/커버/직접 밟기
- 투구수·컨디션에 따른 제구 저하, 선발/불펜 운영
- 관중석·실시간 전광판·야간 조명 구장, Web Audio 절차 생성 효과음/응원가
- 2026 KBO 실제 기록 기반 선수 능력치 (`KBO_DB_Builder/`로 직접 수집·갱신 가능)

## 데이터

`KBO_DB_Builder/`는 KBO 공식 기록 사이트에서 시즌 기록을 수집해 SQLite/JSON/CSV와
게임용 `kbo_data.js`를 생성하는 파이프라인입니다 (`python build.py --photos --logos`).

> ⚠️ 본 저장소는 **비공식 팬 프로젝트**입니다. 선수 사진·구단 엠블럼 등 권리물은
> 저장소에 포함하지 않으며(로컬 빌드 시에만 생성), 선수명·기록은 공개된 통계 정보를
> 학습·비상업 목적으로 사용합니다. 권리자 요청 시 즉시 조치합니다.

## 로컬 실행

```bash
git clone https://github.com/parksw20/BaseBall
# index.html 더블클릭 (또는 run.bat)
```

사진/로고까지 보려면 `KBO_DB_Builder`에서 수집을 1회 실행하세요.
